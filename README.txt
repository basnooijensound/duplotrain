DUPLO MACHINIST - WEB APP / PWA
===============================

Voor LEGO DUPLO trein 10874.

WAT ZIT ERIN
- liggend tablet-scherm
- dochter als machinist in de trein
- snelheid onder de trein: links = achteruit, midden = stop, rechts = vooruit
- toeterknop
- grote stopknop
- tik op de lampen van de locomotief om de lampkleur te wisselen
- Bluetooth status rechtsboven
- automatische herverbinding als Chrome de trein al kent
- kleurstenen op de rails worden in de web-app verwerkt

BELANGRIJK
Web Bluetooth werkt alleen vanaf een beveiligde HTTPS-webpagina (of localhost).
Daarom kun je index.html niet simpelweg dubbelklikken op de tablet.
De map moet gratis op een HTTPS-host gezet worden, bijvoorbeeld GitHub Pages.

EERSTE GEBRUIK
1. Open de HTTPS-link op de Android-tablet in Google Chrome.
2. Tik rechtsboven op het Bluetooth-symbool.
3. Kies de DUPLO-trein.
4. Chrome onthoudt de Bluetooth-toestemming meestal voor volgende keren.
5. In Chrome: menu met 3 puntjes > Toevoegen aan startscherm / App installeren.
6. Daarna start hij fullscreen als een gewone app.

KLEURSTENEN
Rood   = remmen/stop
Geel   = toeter
Groen  = stoppen + richting omkeren
Wit    = lamp aan/uit
Blauw  = watergeluid, kort stoppen, daarna verder met vorige snelheid

LET OP
De eerste versie is gebaseerd op het openbare LEGO Wireless Protocol en de bekende 10874-poorten.
Test eerst met lage snelheid. Mocht jouw trein een commando net anders interpreteren, dan kunnen we de web-app direct aanpassen zonder opnieuw een APK te installeren.
